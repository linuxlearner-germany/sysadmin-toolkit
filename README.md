# 🧰 sysadmin-toolkit

A curated collection of practical tools, scripts, and bootable environments for system administration, troubleshooting, and recovery.

---

## 🚀 Overview

* 🛠️ System diagnostics & repair
* 💾 Disk management & recovery
* 🌐 Networking & security
* 🔁 Bootable environments (Ventoy, MediCat, Hiren’s BootCD)
* ⚙️ Automation scripts (Windows & Debian)
