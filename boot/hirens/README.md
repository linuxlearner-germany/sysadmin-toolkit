# 💿 Hiren’s BootCD PE

Hiren’s BootCD PE is a lightweight Windows-based recovery environment for system repair, troubleshooting, and maintenance.

It is fast, portable, and ideal for quick fixes.

---

## 🚀 Features

* Lightweight Windows PE environment
* Fast boot and low resource usage
* Essential repair and diagnostic tools
* Easy to use interface

---

## 📦 Contents

Hiren’s BootCD includes:

* 🛠️ System repair tools
* 💾 Disk & partition utilities
* 🔑 Password reset tools
* 🔁 Backup & recovery tools
* 🧪 Diagnostic utilities

---

## 🔁 Ventoy Compatibility

Hiren’s BootCD works perfectly with **Ventoy**.

* Simply copy the ISO to your USB
* Boot and select it from the Ventoy menu

---

## 🧰 Usage with MediCat

Hiren’s BootCD can be used **alongside MediCat**.

* MediCat → full-featured toolkit
* Hiren → fast and lightweight alternative

👉 This allows you to:

* Use MediCat for complex tasks
* Use Hiren for quick troubleshooting

---

## 💾 USB Drive Requirements

### 📏 Recommended Size

* **Minimum:** 8GB
* **Recommended:** 16GB+

---

### 📦 Storage Usage

* Hiren’s BootCD → ~3GB
* Additional ISOs → optional

---

### ⚡ Performance

* USB 2.0 works, but **USB 3.0+ recommended**
* Faster drives improve boot speed

---

## ➕ Custom ISO Support

You can combine Hiren’s BootCD with other tools:

```bash
boot/iso/custom/
```

### 💡 Example

```bash
boot/iso/custom/hirens.iso
boot/iso/custom/medicat.iso
boot/iso/custom/windows10.iso
```

## ⚙️ Setup

### 1. Download Hiren’s BootCD

👉 https://www.hirensbootcd.org/

---

### 2. Add ISO

Copy the ISO file to your Ventoy USB.

---

### 3. Boot

## ⚖️ Hiren vs MediCat

| Feature  | Hiren’s BootCD | MediCat USB      |
| -------- | -------------- | ---------------- |

| Speed    | Fast           | Slower           |
| Tools    | Essential      | Extensive        |
| Use Case | Quick fixes    | Full toolkit     |
